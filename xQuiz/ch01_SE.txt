// 題目 1: 軟體的本質
::軟體本質::下列何者最能精確描述「軟體的本質」？{
~軟體是一種實體的產品，具有磨損性。
=軟體是一種邏輯與抽象的實體，不會因為使用而磨損。
~軟體是硬體的一部份，其開發過程與製造業相似。
~軟體開發過程主要在於組裝既有元件，而非創造新邏輯。
}

// 題目 2: 工程的意義 (在軟體工程中)
::工程意義::在「軟體工程」中，「工程」一詞的意義最主要是指？{
~使用最先進的編程語言和技術。
~追求藝術性與創造力的程式碼設計。
=採用系統化、紀律化與可量化的方法進行軟體開發、操作與維護。
~確保軟體以最快速度完成，不考慮成本和長期維護。
}

// 題目 5: 軟體工程與程式撰寫的差異 (範圍)
::工程與程式差異 1::軟體工程 (Software Engineering) 與單純的程式撰寫 (Programming) 之間，最大的差異點之一在於：{
~程式撰寫只使用高階語言，而軟體工程只使用組合語言。
=軟體工程涵蓋了需求分析、設計、測試、維護等整個生命週期，而程式撰寫主要專注於撰寫程式碼實現功能。
~程式撰寫注重團隊合作，而軟體工程則通常由單人完成。
~軟體工程的目標是撰寫最小、最快的程式碼。
}

// 題目 6: 軟體工程與程式撰寫的差異 (複雜度)
::工程與程式差異 2::面對大型且複雜的軟體系統，軟體工程學科強調採用何種方法來管理其複雜度？{
~持續增加開發人員以加快進度。
~完全避免使用外部函式庫。
=分解 (Decomposition)、抽象化 (Abstraction) 與模組化 (Modularity)。
~只使用單一、巨大的程式檔案來減少檔案數量。
}

// 題目 7: 軟體工程師的工程道德 (資料隱私)
::工程道德 1::一位軟體工程師發現其開發的應用程式存在一個漏洞，可能導致用戶個人資料外洩。根據工程道德，他最優先的責任是？{
~假裝不知道，以免影響產品發布時程。
~向公眾發布該漏洞，以證明程式設計的複雜性。
=立即修復該漏洞，並在必要時通知相關方潛在的風險。
~將該漏洞記錄在內部文件中，但不採取任何行動。
}

// 題目 8: 軟體工程師的工程道德 (誠實與公正)
::工程道德 2::在向客戶報告專案進度時，軟體工程師發現專案將會延期。根據工程道德規範，下列哪種行為是正確的？{
~隱瞞延期事實，直到最後一刻再告知。
~誇大已完成的工作量，以維持客戶信心。
=誠實且公正地報告實際進度、延期原因及預計的解決方案。
~將延期完全歸咎於其他團隊成員的錯誤。
}
